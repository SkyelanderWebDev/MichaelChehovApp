## Scope shipped in this build

1. **Taxonomy reorder (16 categories).** Chart order is now 1–3 PsychoPhysical Exercises, 4–6 Characterization, 7–10 Emotional Life, 11–13 Esthetics, 14–16 Transformation. `CHART_FAMILIES` order matches the numbering; the outer family-arc ring is now computed from live category data instead of a hard-coded conic-gradient.
2. **Psychological Gesture, category 16 (Transformation).** Exact Dawson scaffold, labels only:
   - Description: `Psychological Gesture = Archetypal Gesture (Pure Will / what) + Feeling (how) + Thinking (why)`
   - `Inspiration` (no children, drawable parent-only), `Imagination` (`Body`, `Behavior`, `Activity`), `Intellect` (`Way`, `Win`, `Loss`)
   - Appears immediately in Quick Draw, Journal draws, and the daily tool pool. Not a Movable Centers-style multi-component recipe.
3. **Quick Draw ritual redesign.** Numbered/colored chart key collapses/expands directly under the chart (collapsed by default on the Chart tab; Journal chart unchanged). Draw action is centered, card-deck style, and sits in/near the first viewport at 390×844. Result reveals as a centered card object (sourced labels + sanctioned description only) with a reduced-motion-safe reveal animation. Veiling, history, filters/select-all/examples, and category details remain available but subordinate. Lock / Draw another / Begin POA / history / veiling behavior preserved.
4. **PDF export from saved/completed POA history.** Every history day with a saved POA has `Export PDF` (share → download → mailto fallback chain); preview-only rows without POA content do not offer homework export. PDF/text now carry a student name line: profile display name → auth metadata full name → `Name: __________________` fallback. Legacy auto-generated display names that equal the email local-part are ignored, and new signups no longer seed display names from email. Date, tool/category/parent/child/components, POA content, and the NMCA/Lisa attribution footer are included. No class/show, no email address.
5. **Connect shell polish.** Kicker `Community`, honest "later beta updates" copy, `Planned` pills on the three seeded cards (studios/teachers, events/calendar, group chat). No invented events, studios, teachers, or locations.
6. **Hub fix.** `Inspired Action` hub title no longer flex-squeezes to one clipped line at narrow widths.

## Follow-up pass (same day, pre-approval review feedback)

1. **Family-arc alignment fix.** The outer conic-gradient started `from -90deg`, rotating every family slice a quarter turn counter-clockwise off its numbered nodes (CSS conic angles already start at 12 o'clock — the same frame as the node-slot math, which offsets from the -90° math angle). Now `from 0deg`, and the builder moved to `getFamilyArcGradient()` in `circleChartCatalog.ts` beside the node-geometry helpers so the exact gradient string is unit-testable (jsdom drops `conic-gradient` from inline styles, so the component style attribute cannot be asserted directly). New tests in `circleChartGeometry.spec.ts` pin `from 0deg`, the five slice ranges (0–67.5, 67.5–135, 135–225, 225–292.5, 292.5–360), and slice-boundary/slot-boundary agreement. Browser-verified: computed style shows top-start slices; purple sits behind 01–03, blue 04–06, amber 07–10, teal 11–13, rose 14–16.
2. **Post-draw actions: Add Note replaces Lock; Begin POA starts the POA flow.**
   - Result-card actions are now `Add Note` / `Begin POA in Journal` / `Dismiss`. The single-draw Lock toggle is removed (its `singleLocked` state deleted from `ChartPage.vue`; the `quickDrawLock.ts` data layer and its unit spec are unchanged). Movable Centers per-component locks remain exactly as before, including the fully-locked "Locked" button state.
   - `Add Note` opens an inline note panel on the revealed card. Saving uses the EXISTING per-day Flyback reflection (`flyback_note`) — no new table, no schema change. Signed-in: if no practice exists for today, the drawn tool is first persisted as today's preview via `setPreview` (which also logs the draw), then `saveFlybackNote` writes the note; opening the panel prefills today's existing Flyback note so Chart edits the same note Journal shows rather than blind-overwriting. Completed (locked) days refuse with an explanatory status. Signed-out: an inline tester-access message, consistent with the Journal gate; nothing is written.
   - `Begin POA in Journal` (signed-in) persists the draw as today's preview and calls `startTodayPractice`, so Journal opens with that exact tool selected, the day started, and the POA card active. `setPreview`/`startTodayPractice` store guards mean an already started/completed day is never clobbered — Journal then shows the existing locked day. Signed-out keeps the previous sessionStorage `?preview=quick-draw` hand-off (tester gate, applied as preview after sign-in). Store failures fall back to that same hand-off.
   - Tests: 3 new e2e cases in `category-detail.cy.js` (action set with no Lock button; note panel + signed-out gate message; signed-out Begin POA lands on `/journal?preview=quick-draw` with the tester gate). Signed-in start-from-chart is covered by the store lock guards' existing unit specs plus the guest-path e2e; live signed-in browser smoke was not run (no tester credentials against production data).
